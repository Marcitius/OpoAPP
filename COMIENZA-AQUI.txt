OpoGC v13.2 - ACTUALIZACION DESDE v13.1

Este ZIP NO es el proyecto completo. Contiene solo archivos nuevos/modificados.
Necesitas tener aplicada v13.1, que incluye editar en directo y elegir modo.

1. Descomprime y abre la carpeta actualizar.
2. Copia TODO SU CONTENIDO a la raiz de tu proyecto OpoAPP, donde YA esta
   package.json. Acepta sustituir. Conserva rutas de app, components, lib, etc.
   No subas una carpeta nueva llamada actualizar. No hay archivos que borrar.
3. En esa raiz: npm ci, npm run typecheck, npm test, npm run build.
4. Sube los cambios a la rama conectada a Cloudflare Pages.
   Build command: npm run build
   Build output directory: out
   Root directory: donde este package.json (vacio si esta en la raiz).
5. Conserva las variables actuales de Supabase. No ejecutes SQL.
6. Tras el despliegue, acepta la actualizacion de OpoGC en TODOS los dispositivos.
   No borres datos del navegador, ni reinstales la PWA para aplicar este parche.

USO
- Barra principal: Hoy / Biblioteca / Repasar / Progreso / Mas.
- Salir: guarda la sesion para continuarla despues.
- Hoy, Biblioteca o Mas > Temario y planificacion > Continuar sesion.
- Dentro de una tarjeta: menu de tres puntos > Finalizar sesion.
- La vuelta completada conserva su resumen hasta que pulses Finalizar sesion.
- Intentar empezar otra seleccion permite continuar o finalizar la anterior.
- Cambiar de dispositivo requiere que el estado haya llegado por la
  sincronizacion habitual; sin conexion, se envia al volver a conectarte.
