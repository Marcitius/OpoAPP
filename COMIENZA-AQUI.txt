OpoGC v14 - MATERIAL DE ESTUDIO

1. Descomprime y abre actualizar.
2. Sube TODO EL CONTENIDO de actualizar a la raiz de OpoAPP en GitHub,
   conservando las rutas y aceptando sustituir archivos.
   No subas una carpeta adicional llamada actualizar.
3. Sube juntos package.json y package-lock.json: el editor tiene dependencias nuevas.
4. En Cloudflare Pages:
   Build command: npm run build
   Build output directory: out
   Root directory: donde esta package.json
5. Conserva las variables actuales de Supabase y vuelve a desplegar.
   No ejecutes SQL ni crees otra base de datos.
6. Acepta la actualizacion de OpoGC en tus dispositivos cuando aparezca.

El parche incluye los archivos de la reparacion v13.2.1 necesarios para el
commit de GitHub inspeccionado, ademas de Material. No hay borrados manuales.
El build aparta los mismos seis archivos antiguos comprobados y conserva copia.

COMO USARLO
Biblioteca > Material de estudio (tambien disponible en Mas).
- Nuevo tema / Nuevo subapartado.
- O Copiar estructura de Biblioteca: selecciona, revisa y confirma.
- Leer / Contenido de... abre el documento editable.
- Pega directamente desde ChatGPT: titulos, negritas y listas aparecen formateados.
- Mas formato (tres puntos) muestra herramientas adicionales.
- Importar texto admite TXT, MD y HTML y lo anade al documento actual.
- Cerrar espera al guardado local; la sincronizacion sigue siendo automatica.
