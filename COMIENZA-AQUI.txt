OpoGC v13.1 - ACTUALIZACION DESDE v13

1. Descomprime el ZIP y abre actualizar.
2. Sube TODO EL CONTENIDO de actualizar a la raiz de OpoAPP, aceptando
   sustituir archivos. Conserva las rutas de app, components, lib, tests, docs.
   package.json debe quedar junto al package.json anterior.
   No subas una carpeta nueva llamada actualizar.
3. Cloudflare Pages: Settings > Builds & deployments > Build configuration.
   Build command: npm run build
   Build output directory: out
   Root directory: donde este package.json (vacio si esta en la raiz).
4. Conserva tus variables actuales de Supabase. Vuelve a desplegar.
5. No necesitas ejecutar SQL ni volver a configurar Supabase.

USO
- Tarjeta abierta > menu de tres puntos > Editar tarjeta.
- Coleccion > Empezar repaso > Quitar de nombre y continuar.
- Coleccion > Quitar de aqui, en la fila de la tarjeta.
- Biblioteca > Seleccionar > Estudiar seleccion > elige modo.
- Estudiar > Estudiar tarjetas de esta seleccion > elige modo.

El parche requiere la v13 entregada, no es un proyecto independiente.
No borra archivos automaticamente; no elimina datos ni reinicia el estado.
No hay eliminaciones entre v13 y v13.1.

Si aun aparecen errores de @/db en Cloudflare:
Los registros anteriores mostraban archivos que no estaban en v13:
 app/api/annotations/route.ts
 app/api/files/route.ts
 app/api/files/multipart/route.ts
 app/api/state/route.ts
 app/api/storage-status/route.ts
 wrangler.json
Este parche no soluciona por si solo esa mezcla de versiones. Guarda una copia
del repositorio y compara esas rutas con la entrega completa v13 antes de
retirarlas. Mantener codigo antiguo que no esta en la entrega puede impedir
compilar aunque los archivos nuevos esten actualizados.
